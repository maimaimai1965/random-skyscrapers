[Описание](#описание)


## Описание

Приложение реализует задачу, описанную в [_Desc.pdf_](Desc.pdf).

Замечания:

1. [Визуализация](#Визуализация) реализуется не через графический интерфейс, а имитируется через консоль.  

Уточнения алгоритма:

- значения, выводящиеся на форме, находятся в пределах от 1 до 1000 (включительно);
- сразу после генерации при первом выводе сортировка не выполняется;
- максимальное количество элементов, выводящихся на форме - 100;
- если на форме выбрано число от 1 до 30 (включительно), то будет сгенерировано новое множество элементов с количеством 
  равном этому числу.


## Визуализация

Меняем только первый совпавший элемент
