## Описание задания

Приложение реализует задачу, описанную в [_Desc.pdf_](Desc.pdf).

Уточнения алгоритма:

- значения, выводящиеся на форме, находятся в диапазоне от 1 до 1000 (включительно). Значение 1000 задается константой
  [_RandomSkyscrapers_](src/main/java/RandomSkyscrapers.java)._MAX_NUMBER_VALUE_;
- сразу после генерации множества случайных чисел сортировка не выполняется;
- первая сортировка на форме віполняется в убівающем порядке (Descending order).
- максимальное количество элементов, выводящихся на форме - 100. Это значение задается константой
  [_RandomSkyscrapers_](src/main/java/RandomSkyscrapers.java)._MAX_ELEMENT_COUNT_;
- если на форме выбрано число от 1 до 30 (включительно), то будет сгенерировано новое множество элементов с количеством 
  равном этому числу. Значение 30 задается константой
  [_RandomSkyscrapers_](src/main/java/RandomSkyscrapers.java)._THRESHOLD_NUMBER_VALUE_.


## Запуск приложения

Для запуска приложения используется метод [_RandomSkyscrapers.main()_](src/main/java/RandomSkyscrapers.java). 

Если приложение запускается с аргументом _**console**_, то будет запущена [визуализация для консоли](#консоль).

В остальных случаях запускается [визуализация с использованием Swing](#ui-swing).


## Визуализация

Сделано 2 варианта реализации:
 - UI реализация, использующая Swing;
 - консольная реализация;


### UI (Swing)

UI реализован с использованием Swing.


### Консоль

Визуализация реализуется не через графический интерфейс, а имитируется через консоль.

При запуске приложения в консоли выводится строка для ввода количесва элементов:

```text
How many numbers to display?:
```
В ней мы указываем нужное количество, после чего выводятся строки с этими элементами, разбитыми по блокам, которые 
соответствуют колонкам в задании:

```text
How many numbers to display?: 12
[ 1, 156, 77, 220, 703, 277, 130, 646, 982, 650 ] [ 854, 823, , , , , , , ,  ]
Enter (S)ort or (R)eset or Value from the list or (Q)uit: 
```
Далее можно вводить:

- S(s) - для сортировки элементов. При повторном выборе этой опции будет выполнена сортировка в обратном порядке;
- R(r) - для новой генерации множества элементов с переходом к заданию их количества;
- Q(q) - для выхода из приложения; 
- значения из списка: 
  - если это значение меньше или равно 30, то генерится новое множество с количеством элементов равным этому значению;
    Значение 30 задается константой [_RandomSkyscrapers_](src/main/java/RandomSkyscrapers.java)._THRESHOLD_NUMBER_VALUE_;
  - если это значение больше 30, то выводится строка "Please select a value smaller or equal to 30", в которой вводится
    число. На это число будет поменено первое встреченное значение в этом списке равное указанному ранее значению из
    списка;
- другое - выводятся сообщения о неправильном вводе. 

При сортировке производится ее визуализация путем подсвечивания текущего и перемещаемого элемента.
Скоростью визуализации можно управлять с помощью параметра
[_SkyscrapersUiImpl_](src/main/java/SkyscrapersUiImpl.java)._SLEEP_MILLISECONDS_.

Количество элементов в блоке задается константой
[_RandomSkyscrapers_](src/main/java/RandomSkyscrapers.java)._COUNT_ELEMENTS_IN_COLUMN_.
